# Reference material policy

This directory stores indexes, checksums, capability matrices, and analysis notes. Large official downloads should not be committed blindly. Their provenance, version, canonical URL, licence/distribution status, and checksum must be recorded.

Planned subdirectories:

- `epa/` — official source/manuscript/test indexes and traceability maps;
- `aermod-view/` — commercial workflow and interaction analysis;
- `github-projects/` — third-party capability audits;
- `coverage/` — official-versus-implementation matrices.
