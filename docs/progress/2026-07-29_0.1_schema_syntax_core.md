# AERMODKit 0.1 progress 01 — versioned schema and lossless syntax core

- Date: 2026-07-29
- EPA baseline: AERMOD v26135
- Project format version: 1.0
- Package version: 0.1.0a1

## Objective

Start the new core package without inheriting PyAERMOD's version-independent dataclass
model. The unit establishes the machine-readable version boundary and prevents unknown
runstream content from being silently deleted.

## Implemented

1. `AermodVersion`, `KeywordSpec`, `ModelOptionSpec`, `SourceTypeSpec`, evidence,
   and diagnostic models.
2. Registry loading by explicit AERMOD version.
3. Initial v26135 CO/SO keyword set: `TITLEONE`, `TITLETWO`, `MODELOPT`,
   `AVERTIME`, `POLLUTID`, `RUNORNOT`, `ELEVUNIT`, `LOCATION`, `SRCPARAM`,
   `SRCGROUP`, and `INCLUDED`.
4. Full v26135 MODELOPT token registry with explicit option ordering and rules.
5. Thirteen source types and their LOCATION/SRCPARAM argument contracts.
6. Lossless AST retaining blank lines, comments, unknown statements, original spacing,
   pathway markers, line numbers, and quoted filename semantics.
7. Preserve writer for exact round trips and canonical writer for deterministic output.
8. Schema, option, source, and structural validation with evidence-capable diagnostics.

## Important evidence decisions

- AERMOD v26135 includes no BETA scientific options, although the `BETA` control flag
  remains part of MODELOPT.
- `RLINEXT` and `SWPOINT` require `ALPHA` and cannot be combined with `DFAULT`.
- `SWPOINT` is present in the July 2026 User's Guide even though the compact source list
  in the Quick Reference omits it from one summary line.
- `GRSM` is registered as a current regulatory chemistry option, but this batch does not
  assert DFAULT compatibility because the Quick Reference does not explicitly state it.

## Verification

The test suite checks:

- registry completeness;
- exact preserve-mode round trips;
- deterministic canonical output;
- quoted INCLUDED filenames;
- unknown-keyword retention;
- DFAULT/ALPHA and option conflicts;
- TTRM/TTRM2 pairing;
- SWPOINT and RLINEXT source contracts.

## Deliberately deferred

- Complete CO/SO keyword extraction beyond the minimum closure;
- RE/ME/EV/OU semantic schemas;
- semantic project/domain objects;
- GIS geometry and emission conservation;
- official AERMOD executable integration and numeric regression;
- project workspace and job ledger.
